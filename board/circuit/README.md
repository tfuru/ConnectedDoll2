## 回路参考

### 電源・保護回路 ブロック

Pch MOSFET (AO3401A) を用いた標準的な逆接続保護（ハイサイド）回路とする。

```
[電源のプラス (+5V入力)] ──┬──> [AO3401A (C15127) の S(ソース)ピン]
                            │
                            └──> [ツェナーダイオード (C78478) の カソード(陰極)]

[AO3401A の G(ゲート)ピン] ──┬──> [ツェナーダイオード (C78478) の アノード(陽極)]
                             │
                             └──> [プルダウン抵抗 100kΩ (C25803)] ──> [GND]

[AO3401A の D(ドレイン)ピン] (正しく電源が入るとここから保護された電源が出力される)
    │
    └──> 🌟 ここが【リセッタブルヒューズ (C2803346)】の入力へ繋がります

※ 動作原理:
  - S(ソース) = +5V入力、D(ドレイン) = 保護後出力。
  - G(ゲート)は 100kΩ で GND へプルダウンされ、正常時 Vgs が負電圧となり MOSFET がON。
  - ツェナーダイオードは カソード=S(+5V側) / アノード=G(ゲート側) に接続し、
    Vgs を約5.1Vにクランプして MOSFET のゲート・ソース間を過電圧から保護する。
  - 逆接続時は Vgs が正となり MOSFET がOFFのまま導通しないため、後段を保護する。
```

```
[AO3401A の D(ドレイン)ピン] ──> [リセッタブルヒューズ (C2803346)] ──> 🌟 各回路の【V_BATT】へ分配

[電池のマイナス(−)] ───────────────────────────────> 🌍 すべての部品の【GND】へ接続
```

### 3.3V DCDCコンバータ回路 ブロック

```
                                 [インダクタ 1.5μH (C467130)]
                                     ┌─── LL ───┐
                                     │          │
[V_BATT] ──┬──> [IN (Pin4)] ─────── LX (Pin3)   ├──┬──> 🌟 各部品の【3.3V】電源へ
           │       │                            │  │
           │    [EN (Pin1)]                     │  └──> [コンデンサ 22μF (C45783)] ──> [GND]
           │                                    │
    [コンデンサ 10μF (C19702)]                  ├──> [分圧抵抗 45.3kΩ (C23058)]
           │                                    │         │
          [GND]                                 │      FB (Pin5)
                                                │         │
                                                │      [分圧抵抗 10kΩ (C25804)]
                                                │         │
                                                │        [GND]
                                                │
                                                └─────── [GND (Pin2)]

※ SY8089AAAC (C78988) は SOT-23-5 パッケージです。
```

### レベルシフタ ＆ LED回路 ブロック

```
                    [74AHCT1G125GW (C12495)]
                          ┌───────┐
            [GND] ─── OE ─┤1  VCC ├─ V_BATT (5V) ──┬──> [コンデンサ 0.1μF (C14663)] ──> [GND]
                          │       │
[XIAO D3 (GPIO5)] ──── A ─┤2    Y ├─ [保護抵抗 330Ω (C23138)] ──> [WS2812B (C4154882) の DIN]
                          │       │
            [GND] ─── GND ─┤3      │
                          └───────┘

※ 74AHCT1G125GW は SOT-353 パッケージです。OEピンをGNDに落とすことで、バッファ出力を常に有効にします。

[WS2812B (C4154882) 単体の電源とパスコン]
  [VDD] ──> V_BATT (5V) ──┬──> [コンデンサ 0.1μF (C14663)] ──> [GND]
  [GND] ──> GND
  [DIN] ──> レベルシフタ出力 (330Ω経由)
  [DOUT] ──> (次のLEDを連結する場合は次のLEDのDINへ)
```

### オーディオ ブロック

```
                       [MAX98357AETE+T (C910544)]
                             ┌───────────┐
     [XIAO D6 (GPIO21)] ────┤ BCLK   VDD ├─ V_BATT (5V) ──┬──> [コンデンサ 10μF (C19702)] ──> [GND]
                             │           │                └──> [コンデンサ 0.1μF (C14663)] ──> [GND]
     [XIAO D7 (GPIO20)] ────┤ LRCLK  GND ├─ GND
                             │           │
     [XIAO D10 (GPIO10)] ───┤ DIN   GAIN ├─ GND (※ 9dBゲイン設定)
                             │           │
   V_BATT ── [10kΩ] ────────┤ SD_MODE   │
                             │      OUTP ├────────────────> 🔊 [スピーカー端子 B2B-PH-K-S(LF)(SN) (C131337) 1pin]
                             │      OUTN ├────────────────> 🔊 [スピーカー端子 B2B-PH-K-S(LF)(SN) (C131337) 2pin]
                             └───────────┘

※ MAX98357A は TQFN-16 パッケージです（上記は機能ピンを抜粋した接続図です）。
※ SD_MODE ピンを 10kΩ 以上の抵抗で VDD にプルアップすることで、L/Rの平均（モノラルミックス）を出力します。
※ スピーカー出力端子（B2B-PH-K-S(LF)(SN)）には、外部スピーカー「ASE02808MR-LW150-R (8Ω)」を接続します。
```

### RTC ブロック

```
                       [DS3231MZ+TRL (C107410)]
                             ┌───────────┐
     [XIAO D4 (GPIO6)] ─────┤ SDA   VCC ├─ 3.3V ──┬──> [コンデンサ 0.1μF (C14663)] ──> [GND]
        │                    │           │
     [4.7kΩプルアップ]       │           │
        │                    │           │
      3.3V                   │           │
                             │           │
     [XIAO D5 (GPIO7)] ─────┤ SCL  VBAT ├─ [CR1220用電池ホルダー (C70381)] のプラス(+)極へ
        │                    │           │
     [4.7kΩプルアップ]       │      GND ├─ GND
        │                    └───────────┘
      3.3V

※ DS3231MZ は SOIC-8 パッケージです。
※ I2CのSDAおよびSCLラインは、3.3V電源へそれぞれ 4.7kΩ (C22843) のプルアップ抵抗を接続します。
※ 電池ホルダーのマイナス(-)極は GND に接続します。
```

### TFカード ブロック

```
                       [DM3D-SF (C719027)]
                             ┌───────────┐
     [XIAO D2 (GPIO4)] ─────┤ MOSI  VDD ├─ 3.3V ──┬──> [コンデンサ 0.1μF (C14663)] ──> [GND]
        │                    │           │
     [10kΩプルアップ]        │           │
        │                    │           │
      3.3V                   │           │
                             │           │
     [XIAO D9 (GPIO9)] ─────┤ MISO  GND ├─ GND
        │                    │           │
     [10kΩプルアップ]        │           │
        │                    │           │
      3.3V                   │           │
                             │           │
     [XIAO D8 (GPIO8)] ─────┤ SCK    CS ├─ GND (※ 常時有効設定)
        │                    └───────────┘
     [10kΩプルアップ]
        │
      3.3V

※ DM3D-SF は SMD タイプの MicroSD カードコネクタです（上記はSPI接続用の機能ピンの抜粋です）。
* 信号線（MOSI, MISO, SCK）は、SDカードの安定した初期化と動作のため、3.3V電源へそれぞれ 10kΩ (C25804) のプルアップ抵抗を接続します。
* CS（チップセレクト）ピンは、GPIOピン数を節約するため直接 GND に接続して常時アクティブ状態にします。
```

## 基板仕様 (PCB Specifications)

- **基板寸法**: 60mm × 60mm
- **角丸**: R=2.0mm
- **取付穴 (マウンティングホール)**: 四隅 52mm x 52mm 位置に M2 ネジ穴
- **GNDベタ (GND Copper Pour)**: 両面（Top/Bottom層）に配置（詳細な描画・孤立銅箔設定等は [AGENTS.md](/AGENTS.md) に従うこと）
- **基板外形とベタの座標位置**: 設定された基板寸法（60mm × 60mm）を基準として、原点 `(0, 0)` からの正の領域に完全に重ねて配置すること（詳細な座標設定のルールは [AGENTS.md](/AGENTS.md) に従うこと）
- **電源配線ルール (1A対応)**: 主要電源ライン（5V, VCC, V_BATT）のパターン幅は標準 `0.6 mm`（最小 `0.5 mm`）とする。その他の信号線は `0.2 mm` とする。
